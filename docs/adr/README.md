One line per decision a later agent could not read from the code, with its reason. Newest first.

- 2026-11-26 — Eval, replay recording, and reasoning sweep ship as ready-to-run scripts rather than results, because `MODEL_API_KEY` is a pull-proof Vercel Secret and the task budget allowed exactly one live endpoint call; fabricating the numbers was the only alternative, so the README publishes the blocker, the commands, and the one measured smoke call instead.
- 2026-11-26 — Uncertain Ember request parameters are settled by a 400-only negotiation ladder that stamps `request_variant` on every result, because no local probe could reach the API ahead of deploy and one gated live call could then prove the accepted path — which it did: `structured+max_completion_tokens`, HTTP 200.
- 2026-11-26 — Strict `response_format` JSON-schema output is the primary extraction path, with the `record_lead` tool and a plain-text JSON parse as fallbacks, because decoding constrained to the schema beats prompt compliance and every path still passes the same fail-closed validation.
- 2026-11-26 — The paid endpoint is protected by a server passcode header plus an `EMBER_ENABLED` kill switch instead of a KV-backed spend ledger, because the caller's browser meter can never enforce the $10 eligibility cap and a passcode closes the hole in an afternoon with zero new infrastructure; a ledger only becomes necessary if the key is ever shared.
- 2026-11-26 — Unknown enum values fail closed with `needs_review` (urgency→emergency, category→real, ungrounded phone→null) and such cards sort first, because in a callback queue a false emergency costs a glance while a sunk gas leak costs a house.
- 2026-11-26 — Phone numbers are trusted only when their digits appear verbatim in the lead, knowingly sacrificing word-spelled numbers to review, because a hallucinated number gets dialed and a flagged one gets read.
- 2026-11-26 — The public default board is a labeled replay of a recorded Ember run (mock remains a labeled fallback, live Ember stays passcode-gated), because the first question every reviewer asked was "did Ember actually run?" and a replay answers it at $0 per view with the endpoint closed.
